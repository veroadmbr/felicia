Publicação

O CMS salva as alterações no repositório do GitHub. A Vercel atualiza o site sozinha em cerca de 1 minuto.

Conexão com o GitHub

  1. No GitHub, abra Settings → Developer settings → Fine-grained tokens e crie um token.
  2. Em Repository access, escolha só o repositório do site.
  3. Em Permissions → Contents, marque Read and write.
  4. Cole o token aqui. Ele fica guardado só neste navegador.
